# REDLINE for SIGNALIS

REDLINE adds dismemberment, physics-driven knockdowns and detached limbs, crawling, and blood effects to SIGNALIS. EULR, STAR, ARAR, and STCR support limb cuts and ragdolls. Enemies keep their settled ragdoll pose while downed and can resume crawling after revival.

## Build

Use the Windows Steam build `20243420` of SIGNALIS, [MelonLoader 0.5.7 x64](https://github.com/LavaGang/MelonLoader/releases/tag/v0.5.7), a .NET SDK that can build .NET Framework 4.7.2, and Python. The project uses the managed assemblies generated by MelonLoader on its first successful launch. The skin map is generated from your installed game.

From the repository root, install the pinned Python dependency and build a local package.

```powershell
python -m pip install -r requirements.txt
python scripts/package.py
```

For a custom Steam library, pass the directory containing `SIGNALIS.exe`.

```powershell
python scripts/package.py --game-dir "D:\SteamLibrary\steamapps\common\SIGNALIS"
```

The script writes `dist/REDLINE-<version>.zip` with the DLL, skin map, default config, source, and license. To compile just the DLL against the default Steam installation, run `dotnet build Source/Redline.csproj -c Release`. For a custom location, add `-p:GameDir="D:\Path\To\SIGNALIS"`.

## Install and configure

With SIGNALIS closed, copy `Mods/Redline.dll` and `UserData/RedlineSkinMap.gz` from the package into the corresponding folders next to `SIGNALIS.exe`. Copy `UserData/Redline.cfg` on first install, or keep your existing config when updating. Move `Mods/Redline.dll` out of `Mods` to disable REDLINE.

Edit `UserData/Redline.cfg` while the game is closed. `Blood` ranges from `0` to `2.5`. `Dismemberment`, `Crawling`, and `Ragdoll` are switches. `DiagnosticLog` records hits and cut parts in `MelonLoader/Latest.log`. `ScenePreviewF8` enables an F8 test that previews a leg cut on a nearby active enemy without reducing its HP.
